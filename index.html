iPhone widget · Scriptable

Install Scriptable on the iPhone. No Apple developer account or signing is needed.

  1. Download the TU962 widget script. Open the file as text, copy its contents into a new script in Scriptable, and name it TU962.
  2. Export your timetable using the button above. Save the JSON file in Files.
  3. Run TU962 in Scriptable, choose Import timetable file, then select that JSON file. You will see a preview.
  4. On your home screen, add a medium or large Scriptable widget. Edit that widget and select the TU962 script.

Scriptable supplies a home-screen widget. iOS controls its outer corners and refresh timing. Some fonts use iOS alternatives; Arcade and Digital use a monospaced font. Small and medium widgets fit fewer classes. This preview does not promise an iPhone lock-screen widget.

Samsung S24 · KWGT and LockStar

For an Android trial, KWGT supplies the timetable content. Good Lock / LockStar places the widget on your lock screen where your One UI version supports it.

  1. Choose Export for KWGT below. Save the file as TU962-widget.json in Download on your phone, allowing KWGT to read that location if requested.
  2. Add a KWGT widget to your home screen and start a blank design. Add a Text item, open its formula editor, and paste the formula below. It changes with the phone’s date; set the phone/widget time zone to Dublin.
  3. Choose font, text size and colours inside KWGT using the appearance values below. Save the widget, then add that KWGT widget in LockStar if available.

This is a manual KWGT design recipe, not an importable preset. File access and LockStar support depend on your installed versions. It shows today’s classes; the “next day” setting applies to the iPhone widget and preview. If the formula cannot read Download, use a folder your KWGT installation can access and change the file address in the formula.

Transfers are manual. Later edits in this web app need another export and import.

Install the web app

On iPhone, open this page in Safari, tap Share, then Add to Home Screen. On Android, use your browser’s Install app or Add to Home screen option. Use the Scriptable or KWGT setup above for a timetable widget.
