This tests real Arcade text rendered into a PNG. It does not replace or change the live timetable widget. The sample is Monday, 05/10/2026.

Download PNG

Test on iPhone

  1. Download the separate Scriptable test script, copy it into a new Scriptable script, and name it TU962 Arcade Test.
  2. Run it and choose Generate sample images. It prepares medium and large images inside the Scriptable app.
  3. Add a separate medium or large Scriptable home-screen widget and select TU962 Arcade Test.
  4. Check font shape, sharpness, colours and whether it renders after closing Scriptable. Compare normal/full-colour and tinted Home Screen appearances.

The widget reads a cached image, so it does not need to run the font renderer in the widget process. This first test shows a fixed sample day; daily schedule image generation is not implemented. Importing your JSON is optional and stays in Scriptable on your phone. Existing timetable files and scripts are not overwritten.
